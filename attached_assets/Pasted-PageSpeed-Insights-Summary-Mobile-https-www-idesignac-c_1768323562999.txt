Recommended Fix Plan (priority order)
Priority 1 — Reduce TBT / JS blocking (biggest win)

Defer/delay non-critical 3rd-party scripts until after first paint / user interaction:

realworklabs, ContentSquare, OutreachGenius, Posthog surveys, Clarity, Facebook, etc.

Audit GTM tags and remove/merge duplicates; load gtag/gtm as late as possible.

Do not load ServiceTitan scheduler bundle sitewide unless needed above the fold (lazy-load on “Schedule” click or when scheduler section is near viewport).

Lazy-load Google Maps JS (only on map interaction / map section visibility).

Priority 2 — Improve LCP (hero)

Ensure hero image is correctly sized for mobile and efficiently served (it’s already webp, but confirm real rendered size vs requested size).

Remove anything above-the-fold that forces layout thrash.

Keep CSS for hero/above-fold minimal and ensure it’s not blocked by slow CSS chunk loading.

Priority 3 — Cache + critical rendering path

Set long-lived caching headers for first-party assets (/_next/static/*) and confirm 3rd-party caching where possible.

Reduce render-blocking CSS (combine critical CSS / reduce unused CSS).

Priority 4 — DOM reduction

Trim homepage DOM complexity (especially the large widget section). Consider:

Pagination/virtualization for long lists

Collapsing/hydrating below-the-fold sections later

Priority 5 — Cleanup

Fix crawlable links in the “Areas” section

Accessibility fixes (aria labels, contrast, touch targets)
